# PHASE 14 — Notifications & Approval Center

Create a centralized approval and notification experience.

## Notification Center

Support categories:

- Inventory
- Sales
- Pricing
- Procurement
- Repair
- Finance
- Security

Examples:

```text
Discount approval required
Stock transfer awaiting approval
Repair estimate awaiting approval
High-value buyback requires approval
Purchase order awaiting approval
```

## Approval Center

Create:

```text
Pending
Approved
Rejected
Expired
```

Each request should show:

- Request type
- Requested by
- Branch
- Amount/value
- Date
- Reason
- Details
- Approve
- Reject

Keep approval UI generic so future workflows can reuse it.
