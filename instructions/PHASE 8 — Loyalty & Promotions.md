# PHASE 8 — Loyalty & Promotions

Build:

- Loyalty programs
- Loyalty tiers
- Points
- Rewards
- Coupons
- Vouchers
- Promotions

Example:

```text
Silver
   ↓
Gold
   ↓
Platinum
```

Customer profile should display:

- Current tier
- Available points
- Lifetime points
- Points earned
- Points redeemed
- Rewards

Build a promotion configuration UI supporting rules such as:

```text
Customer Segment
Product Category
Branch
Date Range
Minimum Purchase
Discount
Reward
```

Keep the rule UI extensible for future promotion types.
